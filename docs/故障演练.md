# 故障演练

每次正式活动前至少跑一次。每项都要记录恢复秒数和结果。

1. 手机短断网：投票期关闭一部手机网络 5 秒再打开。预期：原匿名凭证恢复，不重复计票。
2. 重发请求：在浏览器弱网下投票。预期：客户端使用同一 request ID 最多重试 3 次，服务端最终只保留一票。
3. 公网隧道中断：停止 cloudflared。预期：本机服务和大屏继续，可在管理端切本地 Wi-Fi 码。
4. Godot 中断：关闭 Godot 窗口。预期：7 秒后房间自动暂停；重开 Godot 后恢复同一轮次与轨迹时刻。
5. Node.js 中断：在已锁定至少一行后终止服务，再运行 `SKIP_BUILD=true ./scripts/start-server.sh`。预期：SQLite 检查点恢复，未锁投票重新完整计时。
6. 服务无法恢复：在管理端预先切“强制无服务演示”，再停服务。预期：Godot 不黑屏，持续轮播内置地图。
7. 百人连接：启动服务后执行 `pnpm load-test`。预期：5 个空位各锁定 100 票，ACK P95 不超过 1000 ms，无协议序号回退。

人体验收仍需现场完成：20—30 台真机彩排、5 米可读性、无声模式、色觉缺失模拟，以及未接触项目的学生盲测。这些需要真实人员和现场设备，不能由自动化代替。
