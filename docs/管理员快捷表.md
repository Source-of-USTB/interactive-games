# 管理员快捷表

| 操作 | 什么时候用 |
|---|---|
| 暂停 | 现场要中断一下、等大家安静或等人到齐 |
| 继续 | 暂停后接着走，从断点恢复，不重来 |
| 跳过阶段 | 当前阶段想快点过去（比如没人投票干等） |
| 紧急重置 | 现场卡死、程序跑不下去时；清掉当前进度开新轮 |
| 启动指定关卡 | 讲解、演示、验收时指定某一关 |
| 公网穿透（主入口） | 手机用流量扫的码 |
| 本地 Wi-Fi（备用） | 公网不通时，切完让手机连现场路由器扫 |
| 隐藏（只演示） | 不收手机投票，只放画面 |
| 强制无服务演示模式 | 后台出问题、要大屏先撑住场面时开 |
| 导出匿名轮次 CSV | 活动收尾存档；内容不含姓名、学号、手机号和 IP |
