# 现场运行手册

## 首次配置（只用做一次）

1. 浏览器打开 Cloudflare Zero Trust → **Tunnels** → 新建隧道 → 复制 **Token**（形如 `eyJ…`）。
2. 给这条隧道加 hostname：`play.source-ustb.com` → `http://localhost:3100`。
3. 本机终端执行一次 `./scripts/setup-local.sh`。
4. 打开 `.env`，确认：

```text
PUBLIC_ORIGIN=https://play.source-ustb.com
PORT=3000
```

## 启动

### 方式 A：公网正式活动

开 **三个终端**，按下面顺序各跑一条，**全部保持打开**：

```bash
# 终端 1
cloudflared tunnel run --token <Token>

# 终端 2
node scripts/player-gateway.mjs

# 终端 3
./scripts/start-local.sh
```

停止：三个终端依次按 `Ctrl+C`。

### 方式 B：只用现场 Wi-Fi

```bash
# 终端 1
./scripts/start-local.sh
```

管理页把二维码切到“本地 Wi-Fi”，手机连现场路由器后扫码（路由器不能开“客户端隔离”）。

### 方式 C：临时公网彩排（没配域名）

一条命令即可，地址每次运行都不同：

```bash
./scripts/start-easy-public.sh
```

失败时改用 `./scripts/start-quick-public.sh`，仍不行就分别跑 `./scripts/diagnose-easy-public.sh` 或 `./scripts/diagnose-quick.sh` 看日志（`runtime/logs/`）。

## 启动后检查

1. 浏览器打开 `http://127.0.0.1:3000/admin`，用 `.env` 里的 `ADMIN_TOKEN` 进入。
2. 大屏画面出现二维码，状态显示已连接。
3. 用**不开现场 Wi-Fi** 的手机流量扫码，能打开投票页并投出一票。

## 活动前 30 分钟

1. 笔记本接电源；关闭系统休眠、弹窗、自动更新。
2. 大屏接有线 HDMI/DP；声音先放到 30% 试一句。
3. 跑 `./scripts/preflight.sh`，出现 `[FAIL]` 必须处理完再继续。
4. 按“方式 A”完整启动，做一遍“启动后检查”。
5. 再用一部连现场 Wi-Fi 的手机扫本地码。
6. 完整跑一轮：投票 → 锁票 → 执行 → 自动换下一关。
7. 有余力跑 `pnpm load-test`。

## 活动收尾

1. 管理页导出 CSV。
2. 三个终端依次 `Ctrl+C`。
3. 数据留在 `runtime/game.sqlite`，日志在 `runtime/logs/`，下次运行不会覆盖。

## 备用：只跑后台和网页（容器）

```bash
docker compose up --build -d
```

大屏程序在主机单独跑：

```bash
set -a; source .env; set +a
godot --path apps/godot --fullscreen
```
