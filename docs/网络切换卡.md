# 网络切换卡

| 现象 | 先做 | 管理端操作 | 参与者提示 |
|---|---|---|---|
| 公网扫码打不开，本机正常 | 确认 cloudflared 进程和现场电脑外网 | 二维码切到“本地 Wi-Fi” | 连接现场路由器后重新扫码 |
| 现场路由器也异常 | 保留 Godot 与本机画面 | 隐藏二维码，打开“强制无服务演示” | 当前为自动演示 |
| 公网恢复 | 用移动数据手机先试扫 | 关闭强制演示，二维码切回“公网穿透” | 直接重新扫码 |
| 大屏掉线 | 等待 7 秒看门狗暂停 | 不重置，先恢复 Godot | 手机会显示现场暂停 |

本地 Wi-Fi 必须关闭 AP/Client Isolation。现场电脑尽量用有线连路由器；不把校园网随机分配的内网 IP 当成固定公网入口。
