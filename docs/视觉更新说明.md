# 视觉更新说明

更新日期：2026-09-05。视觉方向：精致科幻，以深色城市、青绿色光效和有体积感的机器人与地砖，统一手机、管理台和大屏。

## 原有玩法与职责

现场电脑运行唯一权威服务。玩家扫码进入 `/join`，查看任务并为当前程序空位投票；服务端负责计票、锁票、平票裁决、程序编译和执行结果。Godot 正式大屏及浏览器备用大屏 `/screen` 消费同一份状态快照与执行轨迹，呈现地图、程序和结果。管理员从 `/admin` 控制关卡、暂停恢复、节奏和展示设置。

```text
手机选择指令 → 服务端计票与裁决 → 编译与确定性执行轨迹
                        ↓
                Godot 大屏 / 浏览器备用大屏
```

本轮流程仍为：加入任务 → 逐行投票与揭晓 → 编译 → 执行。页面表现服从服务端阶段；本次视觉改造未另设投票截止时间，也未修改胜负规则。

## 本次修改

- **统一视觉**：增加 CROWD CODE / 城市协作终端品牌层级，采用深绿黑背景、青绿边界光、浅绿重点数字、低对比城市环境图和一致的中文字体。
- **地图**：新增机器人、地板、墙体和城市背景贴图；保留可辨识的朝向、终点、芯片、开关与门。机器人使用独立朝向提示，地图物件随服务端执行轨迹变化。
- **手机端**：重排任务信息、阶段进度、地图图例和投票按钮，突出当前行号、选中结果和提交状态；补充欢迎卡、可重新打开的玩法说明、Esc 关闭与弹窗焦点管理。提示使用“锁票前可改选”；最后一行揭晓后提示即将编译。
- **备用大屏**：采用地图与共享程序双栏，强化任务、扫码入口、`program.code` 页签、锁定进度及真实每日统计。城市能量显示累计值，不虚构完成目标；密钥失效时返回登录页并显示原因。
- **Godot 正式大屏**：更新主界面、地图绘制和程序面板，共用本次美术资源与配色；继续接收原有状态与执行轨迹，保留既有离线演示入口。
- **管理端**：统一品牌、面板和登录视觉；登录支持回车、表单标签及错误提示，保留原有管理操作。

## 新增美术资源

本次新增资源并调整渲染引用，没有覆盖原有美术文件。生成的 PNG 原图保存在 Godot 素材目录，合计约 7.15 MB；Web 使用同尺寸、同画面的 WebP 编码版本，合计约 0.53 MB。Godot 端使用 PNG。四张图的生成来源与完整提示词见 [美术素材提示词](美术素材提示词.md)。

| 素材 | Web 仓库路径 | Godot 仓库路径 |
|---|---|---|
| 机器人 | `apps/web/public/assets/robot.webp` | `apps/godot/assets/art/robot.png` |
| 城市背景 | `apps/web/public/assets/city-backdrop.webp` | `apps/godot/assets/art/city-backdrop.png` |
| 地板 | `apps/web/public/assets/floor.webp` | `apps/godot/assets/art/floor.png` |

Web 的对应访问地址为 `/assets/<文件名>`；Godot 从 `res://assets/art/<文件名>` 加载。

## 验证与预览

以下命令均从仓库根目录执行：

```bash
# Web 类型及地图展示回归检查
pnpm --filter @codegame/web typecheck
pnpm --filter @codegame/web test

# 全工程类型、测试与生产构建
pnpm check

# Godot 启动检查
godot --headless --path apps/godot --quit-after 2

# 启动 Web 与服务端开发环境
pnpm dev
```
